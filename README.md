## 🚀 Featured Projects

### 🤖 [cargo_bot_ws](https://github.com/AgustinPrietoValdez/cargo_bot_ws) — Autonomous indoor cargo robot

A differential-drive cargo robot developed **sim-first** in NVIDIA Isaac Sim 5.1
with ROS 2 Humble (WSL2), bridged over a Fast DDS Discovery Server. The
north-star goal is to carry laundry to the laundry room using a building
elevator for multi-floor navigation. The robot uses an EKF (robot_localization)
fusing wheel odometry and IMU, SLAM via slam_toolbox, and Nav2 for autonomous
navigation. Target hardware is an STM32 + Raspberry Pi platform.

### 🗓️ [plan](https://github.com/AgustinPrietoValdez/plan) — Personal organization app (desktop + Android)

An offline-first personal organization app covering calendar, tasks, habits,
budget, and anti-waste meal planning. Built as a cross-platform desktop and
Android application with Tauri 2, React, and TypeScript, with Supabase for
sync. MIT licensed.
